# NexGenAI External Integrations

NexGenAI integrates cleanly with external providers while maintaining 100% offline fallback:
- **GitHub API**: Analyzes public user repositories, commit activity, and repository languages.
- **Google Gemini**: Generative AI advisor when `GEMINI_API_KEY` is configured.
- **Web Speech API**: In-browser speech synthesis (TTS) and speech recognition (STT).
